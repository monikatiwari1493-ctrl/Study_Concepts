📚 Backpropagation Concept

Backpropagation is an algorithm used to train neural networks. It calculates how much each weight contributed to the prediction error. The weights are then adjusted using gradient descent.

1️⃣ Forward Propagation

z₁ = x₁w₁ + x₂w₂ + b₁
h₁ = sigmoid(z₁)
z₂ = x₁w₃ + x₂w₄ + b₂
h₂ = sigmoid(z₂)
z₃ = h₁w₅ + h₂w₆ + b₃
ŷ = sigmoid(z₃)

2️⃣ Calculate Error

Loss = ½ (y − ŷ)²

3️⃣ Backpropagation

The error is propagated backwards from the output layer towards the hidden layer using the chain rule.

δoutput = (ŷ − y) × sigmoid'(z₃)
sigmoid'(z) = sigmoid(z) × (1 − sigmoid(z))

4️⃣ Gradient Calculation

∂Loss/∂w₅ = δoutput × h₁
∂Loss/∂w₆ = δoutput × h₂

5️⃣ Weight Update

w(new) = w(old) − η × gradient

where η is the learning rate.
